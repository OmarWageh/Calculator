# Calculator Project

## 📌 Project Description

This is a simple **Console Calculator** project built with C#.

The program asks the user to enter two numbers and then calculates:

* Addition
* Subtraction
* Multiplication
* Division

The program also handles division by zero by displaying an appropriate message.

## 🛠️ Technologies Used

* C#
* .NET
* Console Application

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <https://github.com/OmarWageh/Calculator.git>
```

### 2. Navigate to the project folder

```bash
cd Calculator
```

### 3. Run the project

```bash
dotnet run
```

## 💻 Example

```text
Welcome To My Calculator Project .
Please Enter the First Number: 10
Please Enter the Second Number: 5

The Addition Two Numbers are: 15
The subtraction Two Numbers are: 5
The multiplication Two Numbers are: 50
The Division Two Numbers are: 2
```

### Division by Zero

If the second number is `0`, the program displays:

```text
Cannot divide by zero.
```
